I was writing an integration test for my highcharts feature the other day and I was running into a bug where putting the set up commands into a `before :all` command was failing but putting the commands into a `before :each` block was failing. It turns out that the stuff in a before :all block runs before Capybara initializes so it was not able to visit routes in the before all block.
